# 🛡️ Cristian Castillo | Portafolio & Blog Premium

¡Bienvenido al repositorio de mi portafolio personal y blog técnico! Este sitio ha sido diseñado con una estética **"Cyber Defense"** ultra-moderna y premium, adaptada especialmente para mostrar mi trayectoria y conocimientos en **Ciberseguridad (Blue Team), Redes e Infraestructura**.

El proyecto está optimizado para cargar a la velocidad del rayo, ser 100% responsivo y ser hosteado de forma extremadamente sencilla y gratuita en plataformas como **Netlify** o **GitHub Pages**.

---

## 🚀 Tecnologías Utilizadas

* **HTML5:** Estructura semántica, limpia y optimizada para SEO.
* **Tailwind CSS (CDN Premium):** Estilos fluidos, modernos y minimalistas basados en componentes glassmórficos y micro-animaciones.
* **Google Fonts (Outfit, Inter & JetBrains Mono):** Tipografía premium que combina títulos elegantes de alta tecnología con excelente legibilidad de código y texto largo.
* **Diseño Responsivo:** Visualización perfecta en smartphones, tablets y pantallas de escritorio.

---

## 🎨 Aspectos Destacados del Diseño

1. **Cyber Grid Backdrop:** Un sutil fondo de cuadrícula cibernética con degradados de luz ambiental que emulan un centro de operaciones de seguridad.
2. **Glassmorphism:** Tarjetas de navegación y secciones con bordes semi-transparentes y desenfoque de fondo (`backdrop-blur`).
3. **Interactive Glows:** Respuestas visuales dinámicas (resplandores y desplazamientos tridimensionales suaves) al interactuar con las tarjetas de proyectos y artículos.
4. **Blue Team Badging:** Etiquetas especiales que destacan habilidades críticas (CompTIA Sec+, Docker, Wazuh, Web Dev).

## 💻 Cómo Ejecutar Localmente

No necesitas instalar dependencias pesadas de Node.js ni bases de datos. Todo es HTML estático. Puedes lanzarlo usando cualquiera de estas opciones sencillas:

### Opción 1: Servidor Python rápido
Si tienes Python instalado, ejecuta en tu terminal dentro de esta carpeta:
```bash
python3 -m http.server 8000
```
Luego abre tu navegador en `http://localhost:8000`.

### Opción 2: Extensión de editor
Si utilizas VS Code, instala la extensión **Live Server**, haz clic derecho sobre `index.html` y selecciona **Open with Live Server**.

## 🌐 Cómo Subirlo a GitHub y Desplegarlo en Netlify

Sigue estos 3 sencillos pasos para tener tu sitio en línea hoy mismo:

### Paso 1: Inicializar Git y subir a tu GitHub
1. Abre tu terminal en esta carpeta.
2. Como ya hemos inicializado el repositorio y hecho el commit inicial para ti, solo debes crear un **nuevo repositorio vacío** en tu cuenta de GitHub (ej. llamarlo `mi-portafolio`).
3. Ejecuta los siguientes comandos reemplazando `TU_USUARIO` y `TU_REPOSITORIO` con tus datos de GitHub:
   ```bash
   git branch -M main
   git remote add origin https://github.com/TU_USUARIO/TU_REPOSITORIO.git
   git push -u origin main
   ```

### Paso 2: Vincular y Desplegar en Netlify
1. Ve a [netlify.com](https://www.netlify.com/) e inicia sesión con tu cuenta de GitHub.
2. Haz clic en **"Add new site"** (Añadir nuevo sitio) y selecciona **"Import an existing project"** (Importar un proyecto existente).
3. Selecciona **GitHub** como proveedor y elige el repositorio de tu portafolio (`mi-portafolio`).
4. Deja la configuración por defecto (ya que es HTML estático puro y no requiere comando de compilación) y haz clic en **"Deploy"** (Desplegar).
5. **¡Listo!** En menos de 10 segundos tu sitio estará en vivo con un enlace gratuito `https://tu-sitio.netlify.app`. Puedes personalizar este dominio gratis o usar uno propio si lo deseas.
